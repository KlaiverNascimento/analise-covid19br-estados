# analise-covid19br-estados
Esse projeto visa trazer informações referente a taxa de mortalidade nos estados brasileiros durante a pandemia de COVID-19 (2020-2023). O estudo utiliza Python, SQL e a biblioteca Matplotlib para disponibilização de gráficos analiticos para maiores analises dos casos. Para além do estudo técnico em dados, o trabalho busca preservar a memória do impacto humano e social desse período por meio de registros públicos e transparência analítica. 

## Fonte dos Dados 
Fonte de dados que estou utilizando principalmente vem do repositório do Wesley Cota: [wcota/covid19br](https://github.com/wcota/covid19br)
